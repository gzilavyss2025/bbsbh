**The band system itself lives in `system.mjs`**, which both builders import, so
there is one band head on this canvas and not two. `data-phase2.mjs` holds the
Phase 2 card contents and the measured height of every card on all three pages.

**One rule on the page boards, stated on each of them.** Every card is at its
measured height. The cards this study draws carry their real figures; the rest
carry the card's true geometry with their figures **ghosted**. The first draft
printed figures into them and the floor page came back with Milwaukee's
opponents on Los Mochis' schedule.

`canvas.json` places every board and holds the two titles and the twenty-five
sticky notes, which carry the critique of each version and each Phase 2 finding.

## Regenerating

**The artboards are generated, not hand-written.** Records is 61 door rows plus
a 10×2 inning table plus 18 season counts and has to be drawn at its true
3,238px; and the four versions differ only in the band furniture, so the cards
are written once and the furniture varies by version.

```
node .scratch/team-one-scroll/canvas/records/build-records.mjs
node .scratch/team-one-scroll/canvas/build.mjs
node .scratch/team-one-scroll/canvas/build-phase2.mjs
```

That writes every `project/*.dc.html`. Edit `system.mjs` (the band furniture),
`build.mjs` / `build-phase2.mjs` (the card renderers) or `data.mjs` /
`data-phase2.mjs` (the values), never the generated `.dc.html` files.

**`canvas.json` is hand-positioned** — Gary moves the notes in the editor — so
`build.mjs` refuses to overwrite it and writes `canvas.proposed.json` instead.
To publish a layout change, run `merge-canvas.mjs` against the LIVE index:

```
node .scratch/team-one-scroll/canvas/merge-canvas.mjs <live canvas.json> <out canvas.json>
```

It adds only the Phase 2 keys and passes every Phase 1 board, note and
coordinate through untouched. Never publish the generated index — it drags every
sticky back to where the script first put it.

> **The Phase 1 `.dc.html` files on disk differ textually from the ones
> published**, because moving the band system into `system.mjs` reordered their
> CSS. They were verified render-equivalent rule by rule before that landed, and
> they are deliberately **not** republished: the published boards are the ones
> Gary signed off on.

To publish, copy `project/` into the session scratchpad — the Artifact tool
refuses a `root` outside the working directory — and send it in one call:

```
Artifact  url: https://claude.ai/artifact/NV6fz4ywi3d3nvX5rdRa8s
          root: <scratchpad>/canvas
          file_path: <scratchpad>/canvas/project/canvas.json
          files: every project/*.dc.html
```

Send `canvas.json` only when the layout, the notes or the title change.

## Looking at the boards without publishing

```
node .scratch/team-one-scroll/canvas/look.mjs <outDir> V4-Loaded.dc.html ...
node .scratch/team-one-scroll/canvas/measure-heights.mjs      # frame sizes
node .scratch/team-one-scroll/canvas/measure-board.mjs P2-Jump.dc.html ".jump__row"
node .scratch/team-one-scroll/canvas/measure-furniture.mjs    # what the bands cost
```

Renders an artboard at 390px and slices it into readable strips. The `.dc.html`
files are plain HTML apart from the `<x-dc>`/`<helmet>` wrapper, so the script
strips those three tags and screenshots what is left. Every version here was
looked at this way and revised before it was published.

## What the boards are

**Every figure is real**, scraped off a running dev server on 2026-09-21 with
`../scrape-standing.mjs`, and every colour is the value the app computes, read
with `../computed.mjs`. Milwaukee's card heads are navy `#12284B` under a gold
`#A6801F` edge; Wilson's are navy `#00274d` under crimson `#98002e`; Los Mochis
is **unthemed** — `headerThemeFor` returns null for it, so its heads are
graphite on transparent.

Records is drawn at **true proportion**. A placeholder would hide the crowding
that is the whole problem in this band.

No application file has been changed by this study.
