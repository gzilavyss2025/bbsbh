The Cancellation — round 2

Logos now claim the top half of the ring, cut off wherever they run past the inner circle. Scores claim the bottom half, sized up, with the abbreviation captions gone. The venue/date ring text is set with textLength against each arc's true path length, so it stretches or compresses to fit any stadium name or date exactly — no hard character limit.

  • Removed the CHC / MIL abbreviation captions

  • Date now reads the full day of week
