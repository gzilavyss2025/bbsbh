A pitch-by-pitch mode for the play log

Research only, nothing built. Today Pitch type and Horizontal location test the last pitch of the plate appearance, the one the result came on. A pitch mode would ask about every pitch.

What the store already holds

The 2015-on (Baseball Savant) store is already one row per pitch: pitch type, the count before it, plate_x (left-right), the call (ball, called strike, swinging strike, foul, in play), batter, pitcher, inning, outs, runners and score. The page throws the per-pitch rows away when it builds plate appearances, to save memory on a phone. So most of a pitch mode needs no new data.

What the store does not hold: pitch speed, spin, height in the zone (plate_z), and break. The 1961–2014 history store has pitch sequences only (ball / strike / foul letters), no type or location.

Questions it unlocks

  • How often does a batter chase (swing at) a pitch off the plate on 0-2? needs only the current store
  • Whiff rate on sliders from lefties to righties. current store
  • What did he throw on 3-2 with the bases loaded? current store
  • First-pitch strike rate by a pitcher, or a club, by month. current store
  • Who throws the most 100 mph pitches; whiffs on high fastballs. needs speed and plate_z added to the store
