What works

  • One set of five groups (Who · Pitch · Result · Situation · Game) shared by every direction — keep it whichever wins.
  • Tabs above everything; Streaks/Games keep their own cards under the same tabs.
  • C's empty state turns "Try one" into the starting doors.

Recommendation: C with A's drawer

  1. Top: Plays / Games / Streaks tabs.
  2. Filter row: set filters as yellow chips (tap to change, × to clear), then dashed quick-add chips for the four most common unset ones (Batter, Pitcher, Result, Seasons), then + More filters.
  3. More filters: A's grouped drawer with a find box — bottom sheet on phone, a five-column panel under the row on desktop.
  4. Typed box: one slim line under the row; it turns into chips.
  5. Empty page: Try one doors. Built page: three-fact card, then rows.

Fan: tap Batter + Result, done. Researcher: More filters, one sheet, every lever grouped.
