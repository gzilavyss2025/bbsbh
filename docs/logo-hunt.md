# Logo hunt: the marks and eras we still need

A checklist you can work through without `npm run dev`. Part 1 lists every MLB logo era to
find, per club. Part 2 lists minor-league eras already filed in
`src/lib/data/season-marks.json` that have no art.

How to use it: find the art, then file it in the dev-only Eras tab (`/identity-lab?nointro`,
`docs/identity-lab.md`). The tab writes `public/logos/historical/` and the table. This file
is a snapshot of 2026-10-22; regenerate it after you file art. Art rules: SVG preferred, or a
transparent 512×512 PNG; the mark as it looked in that era, not a redraw.

## Part 1. MLB eras to find

Source: [SportsLogos.net](https://www.sportslogos.net/teams/list_by_league/4/MLB/MLB/logos/),
each club's "Primary Logos History", fetched 2026-10-22. The year ranges are theirs. Two
cautions, and both are my inference, not facts from the source:

- That site splits small tweaks (a new outline, a recolour) into separate eras. Some rows
  look the same at 40 px. Merge rows when you judge the change too small. The app files an
  era only when the mark differs enough to matter.
- A row's status comes from overlapping years only. The table's own splits can differ from
  this list, so check the club in the Eras tab before you hunt.

Each club's last row is today's mark. The CDN already serves it, so it is not listed. Rows that
already have art are not listed either; the count is under each club. Eras before 1901 are left out.
Boston and Milwaukee Braves and St. Louis Browns years are not researched (SportsLogos.net files
them on other pages); only what the table already holds appears for them.
