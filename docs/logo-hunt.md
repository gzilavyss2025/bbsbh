# Logo hunt: the marks and eras we still need

A checklist you can work through without `npm run dev`. It has two parts. Part 1 lists
eras already filed in `src/lib/data/season-marks.json` that have no art file yet. Part 2
lists the MLB logo eras from outside research, with their status against the table.

How to use it: find the art, then file it in the dev-only Eras tab (`/identity-lab?nointro`,
`docs/identity-lab.md`). The tab writes `public/logos/historical/` and the table. This file
is a snapshot of 2026-10-22; regenerate it after you file art. Art rules: SVG preferred, or a
transparent 512×512 PNG; the mark as it looked in that era, not a redraw.

## Part 1. Filed eras with no art

90 eras across 56 clubs. An era with no art draws its abbreviation in a serif face. A `like` note means the era borrows an MLB club's mark, so art is optional there.

## Part 2. MLB logo eras

Source: [SportsLogos.net](https://www.sportslogos.net/teams/list_by_league/4/MLB/MLB/logos/),
each club's "Primary Logos History", fetched 2026-10-22. The year ranges are theirs. Two
cautions, and both are my inference, not facts from the source:

- That site splits small tweaks (a new outline, a recolour) into separate eras. Many rows
  below look the same at 40 px. Merge rows when you judge the change too small. The app
  files an era only when the mark differs enough to matter.
- A row marked "filed" matched on overlapping years only. The table's own splits can differ
  from this list, so check the club in the Eras tab before you hunt.

The last row of each club is today's mark. The CDN already serves it, so nothing is needed.
Eras before 1901 and a club's pre-franchise years are left out.
