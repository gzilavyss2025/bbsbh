# Ponytail audit — 2026-09-30

A whole-repo audit for over-engineering. It lists what to delete, shrink or
replace with a platform feature. It does not look for correctness bugs,
security holes or slow code.

## How it was run

- **Tool:** the `ponytail-audit` skill from
  [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) v4.10.0
  (commit `e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156`). The skill lists findings
  and applies nothing.
- **Method:** five read-only agents each audited one part of the repo, using the
  skill's tags (`delete`, `stdlib`, `native`, `yagni`, `shrink`). Each agent was
  told to check every finding with a search before it reported the finding, and
  to mark anything it did not check as "(inferred)".
- **Left out on purpose:** the spoiler seal (`SealBox`, the reveal-only modules,
  `spoiler-manifest.json`), the nested `CLAUDE.md` files, the ADRs and the lint
  guard scripts. They are policy, not bloat.
- **Verified by hand before the first cuts:** `vsClub.js` has no caller,
  `diamond-options.html` has no reference, `ordinal()` has 19 definitions in
  `src/` and `lib/format.js` already exports it, `hashFromReply` is defined 4
  times in `api/`, `ipToOuts` is defined 7 times in `src/`, `.scratch/` holds
  2,510 tracked files (152 MB).
- Line counts are estimates. Findings marked "(inferred)" in the issues were not
  checked.

## Result

About 2,900 lines of code and docs, and one dependency
(`eslint-plugin-react-refresh`). `.scratch/` adds about 110k lines of notes,
scripts and mocks on top of that. Nothing in the audit is a bug.

## Done in this PR

- Deleted `diamond-options.html` (123 lines). Nothing links to it.
- Deleted `src/api/boxlines/vsClub.js`, a one-line wrapper with no caller. Removed
  its `spoiler-manifest.json` entry and its mention in `docs/api/live-game.md`.
  ADR-0069 still names the file. An ADR is a record of a past decision, so it was
  left as it stands.
- Deleted 26 CSS rules, in 12 partials, for classes that no element uses. Each
  class name was searched for outside the CSS files first. Lowered the
  `--fs-caption` budget in `scripts/check-caption-budget.mjs` from 124 to 123, as
  the guard asks.
- `GameResultFace`, `SeriesParts`, `BoxScore` and `GameView` now import
  `ordinal` from `src/lib/format.js`. Their local copies had the same body.

## Not done, and why

- **Anything that removes a test.** CLAUDE.md says to never delete a test to get
  a green build. `parseServiceTime.js` and the `byteStore` exports are only used
  by tests, so a person decides first (issue #1307).
- **Copies that say they are deliberate.** Some copies of `ordinal()` and
  `hashFromReply` carry a comment that says the copy is on purpose. A person
  decides the convention first (issue #1306).
- **Anything where the audit only inferred the result.** For example, whether
  the Wordmark Lab is finished, and whether the ADR-0070 Redis migration ran.
- **The `vercel.json` build command.** The audit suggested removing it. It is
  `vite build`, and `npm run build` also runs `gen-sitemap`. Check which one
  Vercel uses first (issue #1310).

## Check

For the cuts in this PR: `npm run lint` and `npm test` pass, and
`npm run build` passes. The dev server compiles the changed modules. The
sandbox cannot reach `statsapi.mlb.com`, so no live-game screen was opened.
